# Emotion Detector

AI-based web application for detecting emotions in English text using the Watson NLP service and Flask.

## Project features

- Detect anger, disgust, fear, joy, and sadness.
- Identify the dominant emotion.
- Provide a web interface using Flask.
- Handle blank input and invalid requests.
- Validate functionality with unit tests.
- Analyze code quality with Pylint.

## Technologies

Python, Watson NLP, Flask, Requests, unittest, and Pylint.
